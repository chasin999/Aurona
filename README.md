# Aurona

Aurona is a work-in-progress expert modpack for Minecraft 1.21.1 NeoForge.

## Status

🚧 Early development. Not currently intended for normal gameplay.

## Technical Information

- Minecraft: 1.21.1
- NeoForge: 21.1.248
- Modpack management: packwiz
- Customization: KubeJS

## Development

This repository contains the packwiz metadata, KubeJS scripts and custom resources used by Aurona.
